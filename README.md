# doctor-stranger
Instructions are now hidden by default behind a small "i" toggle top left, instead of a permanent wall of text. Click it to expand, click again to collapse.
* Status readout (left/right gesture + fps) is now a single compact strip top right with small labels under the values, monospace for the data itself.
  
* Bottom dock replaced the 4 text label buttons with a single icon row: a color swatch dot (cycles amber/cyan/jade), a skeleton icon, a speaker icon, a debug icon active state is shown with a subtle warm tint, not a loud filled block.

* One restrained accent color (soft amber, 
#d99a54) used sparingly for the active/highlight state, instead of glowing amber text everywhere.

*Typography Space Grotesk for the UI chrome, IBM Plex Mono for the numeric/status readouts a real pairing instead of default system font.

* Glass panels dark, blurred, thin 1px border — panels sit quietly over the video instead of competing with it.

*Start button is now a plain solid pill, no gradient/heavy glow — the glow is reserved for the actual spell effects on canvas, which is where it belongs.
